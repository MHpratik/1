Volatility 3 & Memory Forensics Vault

Step-by-step operational guide for setting up Volatility 3, acquiring volatile RAM dumps via FTK Imager, and performing deep OS, process, network, and credential analysis.

PHASE 01

Installing Volatility 3 from GitHub (Windows)

Prerequisites: Windows system with Admin rights recommended, Python 3.8+ (Python 3.9 or 3.10 is safest), Git installed from git-scm.com, and an active internet connection.

Step 1: Verify Python & Git Installations

Open Command Prompt or PowerShell and run the verification commands:

python --version && git --version
Step 2: Clone the Volatility 3 Repository

Navigate to your working directory (e.g., Desktop) and clone the repository:

git clone https://github.com/volatilityfoundation/volatility3.git
Step 3 & 4: Navigate and Verify Files

Change into the cloned folder and verify the directory contents:

cd volatility3 && ls
Step 5: Test Volatility Execution

Run the help utility to ensure framework readiness:

python vol.py -h
PHASE 02

Creating a Memory Dump using FTK Imager

  • 1
    Open FTK Imager: Go to the File menu and click on Capture Memory.
  • 2
    Set Destination Path: Browse and specify the destination path where your memory dump file will be saved.
  • 3
    Capture RAM: Click Capture Memory and wait for the dumping process to complete.
  • 4
    Locate `.mem` File: Confirm your generated .mem file resides in the target directory. (Note: If you prefer using a pre-captured sample dump, download it from OSForensics Win11Dump.zip).
PHASE 03

Analyzing the Memory Dump with Volatility 3

Navigate into your volatility3 directory in your terminal and execute the following forensic plugins against your memory sample (e.g., C:\memdump.mem):

1. System Information (windows.info) Initial Triage

Displays core OS version, kernel base, system time, and processor count.

python vol.py -f C:\memdump.mem windows.info
2. Active Process Listing (windows.pslist) Process Analysis

Lists all active processes running at the time of capture (PID, PPID, start time, threads).

python vol.py -f C:\memdump.mem windows.pslist
3. Scan for Hidden Processes (windows.psscan) Rootkit Detection

Scans memory for process objects to uncover hidden or terminated processes bypassed by malware.

python vol.py -f C:\memdump.mem windows.psscan
4. Display Process Tree (windows.pstree) Hierarchy

Displays parent-child process relationships to spot anomalies like explorer.exe spawning cmd.exe.

python vol.py -f C:\memdump.mem windows.pstree
5. Network Connection Scan (windows.netscan) Network Triage

Enumerates active TCP/UDP sockets and connections to detect malicious C2 communication.

python vol.py -f C:\memdump.mem windows.netscan
6. List Loaded DLLs (windows.dlllist) Injection Check

Lists DLLs loaded within specific process memory spaces to detect injected modules.

python vol.py -f C:\memdump.mem windows.dlllist
7. User Hash Dumps (windows.hashdump) Credential Extraction

Extracts LM and NT password hashes of local system users from registry hives in memory.

python vol.py -f C:\memdump.mem windows.hashdump
